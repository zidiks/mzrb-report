Отчёт МЗ РБ

1. Выберите выгрузку из 1С в поле «Основа отчёта» и её вкладку.
2. Выберите большую книгу с цифрами в поле «Файл с расчётами» и её вкладку.
3. Проверьте месяц: вкладка расчётов 01.11 означает октябрь; заголовок 1С должен относиться к этому же месяцу.
4. Нажмите «Сформировать отчёт». Перебирать договоры вручную не нужно.

Основа строк и данные учреждений берутся из 1С. По договору подбираются все рассчитанные суммы месяца, включая нули. Недостающие в 1С договоры с ненулевыми суммами добавляются из большой книги. Данные учреждений для них остаются пустыми — их нужно заполнить вручную в готовом отчёте.
Правильная разбивка сумм 1С по препаратам сохраняется. Общие расходы договора указываются один раз. Перераспределения выводятся отдельными строками после всех позиций своего договора; знак суммы сохраняется.
В самом конце удаляются строки с одними реквизитами без препарата, сумм и данных учреждений, затем договоры собираются в блоки: сначала нерезиденты РБ, затем резиденты, включая добавленные договоры. Блоки сортируются по первому названию лекарства, затем по поставщику; латиница раньше кириллицы. После сортировки позиции нумеруются заново без пропусков. Учреждения и перераспределения номера не получают.

Совпадающие реквизиты договора объединяются; денежные ячейки остаются раздельными. Суммы показываются с двумя десятичными знаками и пробелами между тысячами. Пустые прочерки в названиях учреждений удаляются; кавычки повтора с суммой заменяются полным названием учреждения.
Под итоговой таблицей — список и сумма перераспределений, затем «ВСЕГО до перераспределений». Сводка не прибавляется к итогу повторно.

Результат: 13 полей без фантомных колонок, итоги-формулы. Файл сохраняется в «Готовые отчёты» рядом с большой книгой. Исходные файлы не изменяются.
В подпапке «Проверки» находятся замены, добавления, удаления и замечания. Неоднозначные суммы не распределяются произвольно; причины записываются в проверку без обязательного обхода всех пунктов.

Установка: Установить.cmd. Обновление: кнопка «Проверить обновления». Нужен Microsoft Excel и Windows PowerShell 5.1.
Источник обновлений: https://github.com/zidiks/mzrb-report/releases
