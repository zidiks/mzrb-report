Отчёт МЗ РБ

1. Выберите выгрузку из 1С в поле «Основа отчёта» и её вкладку.
2. Выберите большую книгу с цифрами в поле «Файл с расчётами» и её вкладку.
3. Проверьте месяц: вкладка расчётов 01.11 означает октябрь; заголовок 1С должен относиться к этому же месяцу.
4. Нажмите «Сформировать отчёт». Перебирать все договоры вручную не нужно.

Строки, их порядок, реквизиты и данные учреждений берутся из 1С. Суммы подбираются автоматически по договору; если номер повторяется, учитываются дата и поставщик.
Для найденного договора берутся все рассчитанные суммы месяца, включая нули. Если договора нет в большой книге, его значения 1С сохраняются.
Правильная разбивка 1С по препаратам сохраняется. Общие расходы договора указываются один раз — в первой заполненной строке. Перераспределение включается в отпуск той же позиции, без новых строк.

Результат: 13 полей без фантомных колонок, итоги-формулы. Файл сохраняется в «Готовые отчёты» рядом с большой книгой. Исходные файлы не изменяются.
В подпапке «Проверки» находятся замены и замечания. Если сумма не сопоставилась однозначно, программа сохраняет соответствующие данные 1С и указывает причину; проходить все пункты проверки не требуется.

Установка: Установить.cmd. Обновление: кнопка «Проверить обновления». Нужен Microsoft Excel и Windows PowerShell 5.1.
Источник обновлений: https://github.com/zidiks/mzrb-report/releases
