Отчёт МЗ РБ

1. В поле «Основа отчёта — выгрузка из 1С» выберите файл 1С и его вкладку.
2. В поле «Файл с расчётами» выберите прежнюю книгу с суммами и её вкладку.
3. Проверьте месяц: вкладка расчётов 01.11 означает октябрь. Месяц заголовка 1С должен совпасть.
4. Нажмите «Сформировать отчёт». Список и порядок строк, названия, договоры и данные учреждений берутся из 1С.
5. Суммы за выбранный месяц заменяют только соответствующие поля. Явный ноль заменяет сумму, пустая ячейка и отсутствующая запись сохраняют значение 1С. Перераспределение входит в сумму отпуска той же строки.
6. Если строка не сопоставилась автоматически, укажите её номер из файла 1С при проверке. Значение 0 означает не переносить эту сумму. Новые позиции из файла расчётов автоматически не добавляются.
7. Результат с 13 полями и итогами-формулами сохраняется в «Готовые отчёты» рядом с файлом расчётов. Входные файлы не изменяются. В подпапке «Проверки» сохраняется список замен и пропущенных сумм.

Установка: запустите Установить.cmd. Ярлык появится на рабочем столе.
Обновление: кнопка «Проверить обновления» внизу окна. Настройки и отчёты сохраняются.
Нужен установленный Microsoft Excel и Windows PowerShell 5.1.
Источник обновлений: https://github.com/zidiks/mzrb-report/releases
